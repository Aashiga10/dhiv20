# 🎂 20th Birthday Celebration Website ✨

Special interactive website designed for **November 20 • 11:20 • Chapter 20**!

## 🌟 Highlights & Features
1. **The 11:20 • Nov 20 Synchronicity**:
   - Cosmic alignment badge highlighting 20 years, Nov 20, and 11:20.
   - Interactive "Make an 11:20 Wish 🌠" button with shooting star confetti.
   - Live countdown timer ticking down to Nov 20 at 11:20 AM.
2. **Interactive 20th Birthday Cake**:
   - Number candles **2** and **0** with realistic glowing/flickering flames.
   - Click candles or "Blow Candles" to extinguish with smoke puffs and golden confetti.
   - Slice the cake with the "Cut the Cake" button!
3. **20 Reasons / 20 Wishes Deck**:
   - 20 interactive 3D cards to flip and reveal heartwarming messages & Tamil quotes for each of her 20 years.
   - Progress bar tracking how many cards have been opened.
4. **🎈 Balloon Pop Mini-Game**:
   - Floating colorful balloons that can be tapped to pop with sound effects and reveal sweet blessings.
5. **📸 Polaroid Memory Wall**:
   - Aesthetic tilted polaroid frames ready for her photos.
6. **💌 Secret Sealed 11:20 Letter**:
   - Wax seal with **'20'** that slides open to reveal an emotional, loving birthday letter.
7. **🎵 Ambient Birthday Melodies**:
   - Built-in Web Audio API synthesizer playing a soft birthday chime tune (no external music files needed).
8. **⚙️ Live Customizer**:
   - A discreet "⚙️ Edit Info" button at the bottom right allows you to change her name (e.g., Dhivya, Thangom, etc.) live without touching code!

## 🚀 How to Run & Preview
You can directly double-click or open `index.html` in any browser (Google Chrome, Edge, Safari, Firefox)!

Or start a local server:
```powershell
# Using Python
python -m http.server 8080

# Or with Node npx
npx serve .
```
Then visit: `http://localhost:8080`

## 📷 How to Add Your Friend's Real Photos
Open `index.html`, find the `<div class="polaroid-gallery">` section, and replace the `src="..."` URLs with:
- Local image files placed in this folder (e.g., `src="photo1.jpg"`), OR
- Any online image links!
